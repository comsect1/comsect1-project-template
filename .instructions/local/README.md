# Repository-Local Instruction Index

This directory owns durable guidance unique to this project. Examples include
product boundaries, subsystem ownership, domain rules, interface constraints,
project-specific build or verification requirements, and persistent operational
decisions.

Keep temporary experiments, one-time migrations, and individual work orders in
`20_ops/`. Promote them here only after review establishes a durable project
rule. Local guidance may narrow or strengthen broader instructions but may not
weaken them.

Template synchronization must never overwrite, delete, or replace this
directory. Conflicts with a new common instruction require explicit review.
